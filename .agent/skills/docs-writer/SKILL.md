# Docs Writer Instructions
- `README.md`: Overview, screenshots placeholder, tech stack, setup, env vars, test running, limits, disclaimer.
- `docs/API.md`: Detailed request/response examples for each endpoint.
- `docs/SAFETY.md`: Safety design, crisis detection, guardrails, audit results.
- `docs/DECISIONS.md`: Log of technical decisions (Gemini, SQLite, no auth, deterministic rules).
- `docs/DEMO_SCRIPT.md`: 3-minute demo script (<10 LLM calls).
