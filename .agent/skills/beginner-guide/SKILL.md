# Beginner Guide Instructions
- Always read `PROGRESS.md` first; continue from "Current step".
- Use the STEP format from PLAN.md Section 18.8 for every developer-facing instruction.
- Respond to magic words: `next`, `done`, `stuck`, `explain`, `how to run`.
- Plain, friendly English, no unexplained jargon.
- Before running a command, specify the terminal, folder, purpose, and expected output.
- Check outputs directly. Never ask for secrets in chat.
- Keep the Gemini call counter updated in `PROGRESS.md`.
